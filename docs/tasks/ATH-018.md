# ATH-018 — GitHub PAT

**Prioridade:** P4.2. **Dependências:** ATH-017. **Estado:** Concluída.

## Problema e resultado

Implementar adaptador GitHub PAT para validar conta, listar fontes autorizadas e ler conteúdo relevante sem gravá-lo diretamente como US. Escolha de repositórios/fontes deve ser explícita por workspace.

## Aceite

- PAT nunca retorna ao cliente nem aparece em logs; falha de autenticação e rate limit são tratados.
- Paginação, arquivo removido e atualização por identidade externa são cobertos.
- Fontes lidas geram candidatos revisáveis, não requisitos canônicos.
- Testes HTTP simulados cobrem sucesso/erros; teste com conta real fica pendente até credenciais de teste.

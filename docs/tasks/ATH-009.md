# ATH-009 — Política de referências

**Prioridade:** P1.6. **Dependências:** ATH-001. **Estado:** Concluída.

## Problema e resultado

O backend permite criar referências manuais, mas o produto decidiu que novas referências devem vir de sugestões aprovadas. Preservar referências existentes e leitura/remoção; impedir criação manual pela rota pública antes da IA, sem perder dados.

## Aceite

- API e docs distinguem referência existente, remoção autorizada e futura criação por aprovação de IA.
- Nenhuma UI oferece criação manual. Tentativa de `POST` manual responde erro de produto estável; serviço interno da aprovação poderá criar com validação de URL e workspace.
- Referências antigas continuam visíveis; testes cobrem `http`, `https`, `mailto` e protocolos inseguros.

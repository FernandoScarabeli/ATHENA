# ATH-021 — Verificação de integrações

**Prioridade:** P4.5. **Dependências:** ATH-020. **Estado:** Concluída.

## Problema e resultado

Fechar o ciclo operacional das integrações: contratos simulados, falhas, documentação de configuração, observabilidade básica e checklist de validação real separado.

## Aceite

- Testes automatizados cobrem GitHub/Google, importação repetida, rate limit, revogação, segredo ausente e isolamento.
- Guia de setup usa variáveis de ambiente e contas de teste, sem tokens reais no repositório.
- `test`, `build`, `lint`, migrations e stack local passam. Testes com serviços reais são marcados `Pendente de credenciais` até haver contas de teste; código e testes isolados podem ser considerados concluídos separadamente.

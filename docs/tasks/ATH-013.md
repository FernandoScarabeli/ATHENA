# ATH-013 — Modelo de sugestões de IA

**Prioridade:** P3.1. **Dependências:** ATH-010. **Estado:** Concluída.

## Problema e resultado

`ImpactAnalysis`/`ImpactItem` só representam parte das relações. Modelar sugestões de relação e referência com tipo, alvo/URL, confiança, justificativa, estado `PENDING`/`CONFIRMED`/`DISMISSED`, erro e vínculo com análise/US. Criar migration para banco ATHENA existente.

## Aceite

- IDs de relações pertencem ao mesmo projeto; URLs seguem protocolos permitidos. Resposta do provider é validada antes de persistir.
- Nenhuma sugestão altera a US canônica por si. Migração preserva análises antigas ou explicita conversão segura.
- Contratos compartilhados, `AI_SCHEMA.md` e REST descrevem o novo modelo; testes de schema e migration passam.

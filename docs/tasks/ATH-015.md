# ATH-015 — Aprovação de sugestões na API

**Prioridade:** P3.3. **Dependências:** ATH-014. **Estado:** Concluída.

## Problema e resultado

Criar endpoints autenticados para listar análises/sugestões e aprovar ou descartar cada item. A decisão é transacional e idempotente; só aprovação cria `RequirementRelation` ou `RequirementReference`.

## Aceite

- `VIEWER` lista, mas não decide; `OWNER`/`EDITOR` decidem dentro do próprio workspace.
- Alvo arquivado, outro projeto, URL inválida ou duplicata não cria vínculo. Item mantém estado/erro recuperável.
- Duas aprovações concorrentes não criam duplicatas. Descartar nunca cria vínculo.
- OpenAPI/REST, autorização e testes com PostgreSQL atualizados.

# ATH-007 — Relações na interface

**Prioridade:** P1.4. **Dependências:** ATH-004. **Estado:** Concluída.

## Problema e resultado

A API cria/remove relações; a UI apenas as lê. Oferecer seleção de US alvo do mesmo projeto, tipo e direção explícitos, remoção confirmada e atualização imediata do grafo/detalhes.

## Aceite

- `OWNER`/`EDITOR` gerenciam relações; `VIEWER` apenas consulta.
- Autorrelação, alvo de outro projeto, US arquivada e duplicata não são criados; backend continua sendo a barreira real.
- Dependências e dependentes são identificáveis no grafo e no painel. Erros da API são mostrados sem perder seleção.
- Testar criação, remoção, atualização de cache e restrições.

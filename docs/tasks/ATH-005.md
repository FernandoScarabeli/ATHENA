# ATH-005 — Gestão de pastas

**Prioridade:** P1.2. **Dependências:** ATH-004. **Estado:** Concluída.

## Problema e resultado

A API atualiza pastas, mas a UI só cria/exclui. Permitir editar nome e descrição nas configurações; excluir exige confirmação contextual e move US para `Sem pasta`.

## Aceite

- `OWNER`/`EDITOR` criam, renomeiam, descrevem e excluem; `VIEWER` apenas consulta.
- `Sem pasta` não pode ser renomeada/excluída; nomes vazios ou duplicados recebem erro claro.
- Após mover/excluir, cards e contagens são atualizados sem recarga; US de outros projetos do mesmo workspace também são realocadas corretamente.
- Testar permissões, transação e UI de sucesso/erro.

# ATH-019 — Google OAuth, Drive e Docs

**Prioridade:** P4.3. **Dependências:** ATH-017. **Estado:** Concluída.

## Problema e resultado

Implementar OAuth Google com estado anti-CSRF, escopos mínimos, refresh token cifrado e leitura de documentos explicitamente autorizados do Drive/Docs. Nenhum documento vira US sem revisão.

## Aceite

- Início/callback valida state e workspace; desconexão revoga acesso local. Tokens não aparecem em URL final, API ou logs.
- Arquivos não suportados, permissões revogadas, paginação e refresh expirado têm estado de erro claro.
- Fontes geram candidatos com identidade externa estável.
- Testes simulados cobrem OAuth e leitura; validação com conta real fica pendente até credenciais de teste.
